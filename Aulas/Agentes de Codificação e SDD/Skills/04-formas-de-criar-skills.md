## Resumo da aula

Aula curta de transição. Existem duas formas de criar uma skill:

1. **Manual** — você escreve o frontmatter e o passo a passo do zero (como na aula 02). Funciona, mas **não é eficiente no dia a dia**.
2. **Com IA ("meta")** — usar a IA para criar a skill, assim como no módulo de prompts foi usado o **meta prompt** para gerar prompts.

O professor diz que não cria skills manualmente. Pedir simplesmente "Claude, cria uma skill" funciona, mas a próxima aula mostra uma forma **mais avançada** de criação.

## Conceitos principais
- Mesma lógica do **meta prompt**: IA ajudando a construir o artefato que a IA vai usar.
- Escrever à mão serve para **entender a estrutura**; para produzir, use IA.
