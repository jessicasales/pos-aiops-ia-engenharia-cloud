## Resumo rápido

- **IA** simula o pensamento humano; não é AGI, não é "inteligente" de verdade.
- **3 abordagens**: regras (if-else) → Machine Learning (aprende de dados) → Deep Learning/redes neurais (base dos LLMs).
- **ML** analisa (classifica, prevê, agrupa); **IA generativa** cria conteúdo (texto, código, multimodal).
- O profissional vira **orquestrador** da IA: define arquitetura, gera com IA, **revisa**.
