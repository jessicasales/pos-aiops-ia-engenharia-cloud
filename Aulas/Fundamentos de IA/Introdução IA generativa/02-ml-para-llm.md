## Resumo da aula

Para trabalhar com IA/AIOps **você não precisa virar especialista em Machine Learning** — mas entender o papel dele ajuda. ML (aprendizado de máquina) é o subcampo em que o sistema aprende **padrões a partir de dados** (em vez de regras if-else manuais).

## Conceitos principais

### Tarefas de ML

| Tarefa | O que faz | Exemplo |
|---|---|---|
| **Classificação** | Categoriza dados | spam/não-spam; estampa permitida/não |
| **Regressão** | Prevê valores numéricos | demanda computacional na Black Friday |
| **Segmentação** | Agrupa dados similares | recomendação (Netflix) |

### Limitação do ML tradicional

Exigia **engenharia manual** de features — o engenheiro definia quais características eram relevantes, e cada problema pedia abordagem específica.

### Redes neurais / Deep Learning

Algoritmos de ML organizados em **camadas** conectadas. Deep learning usa 10+ camadas e processa dados **não estruturados** (logs, imagens, texto) — onde o ML tradicional falhava. Aplicações DevOps: detecção de anomalias, previsão de falhas, análise de causa raiz, geração de código.

> Ponto-chave: os **LLMs** (GPT, Sonnet, Opus) **são deep learning** / redes neurais.

## Pegadinhas

- Não confunda "usar IA" com "treinar modelos de ML" — são papéis diferentes.
- O ML tradicional precisava de feature engineering manual; o deep learning aprende as features.
