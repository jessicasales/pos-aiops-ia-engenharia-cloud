# Desafio Prático: Um Dia na Hill Valley Tech 🚀

Este repositório contém a resolução do desafio prático focado em Engenharia de Prompts aplicada a cenários reais de Infraestrutura, DevOps e SRE dentro da empresa fictícia **Hill Valley Tech (HVT)**.

---

## 🏢 Cenário: O Ambiente da Hill Valley Tech

A Hill Valley Tech possui cinco sistemas principais em produção:
*   **Chronos**: API Gateway e plataforma core (ponto de entrada do tráfego).
*   **Ledger**: Data Warehouse em PostgreSQL (histórico de transações e eventos).
*   **Reactor**: Processamento assíncrono baseado em filas de mensagens.
*   **Beacon**: Ecossistema de observabilidade (métricas, logs e alertas).
*   **Lift**: Produto em fase beta rodando isolado.
